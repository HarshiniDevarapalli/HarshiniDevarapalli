## 📌 Featured Projects

### Aviation Near Miss Intelligence Platform

An AI-powered aviation safety intelligence platform that leverages NLP, vector search, and Retrieval-Augmented Generation (RAG) to analyze near-miss incident reports. The system enables semantic search, trend analysis, and automated insight generation to support proactive aviation risk assessment.

### AI-Based Clinical Trial Matching System

An AI-driven healthcare solution that matches patients to relevant clinical trials by analyzing Electronic Health Records (EHRs) and eligibility criteria. Built using SciSpaCy, BioBERT, and ClinicalBERT, the system extracts medical entities and generates compatibility scores through a hybrid rule-based and machine learning framework.

### Fake Job Posting Detection System

A machine learning-based fraud detection system that identifies deceptive job postings using NLP techniques and domain credibility analysis. By combining TF-IDF features with company and website validation signals, the model achieves approximately 86% classification accuracy.

### Topic Modeling and Text Analytics

An NLP project focused on uncovering hidden themes within large-scale unstructured text datasets. Using embeddings, clustering algorithms, and visualization techniques, the system enables automated topic discovery, content categorization, and text exploration.

### AI-Powered HR Agent

An intelligent recruitment automation agent that streamlines candidate screening through resume parsing, automated evaluation, and decision-making workflows. The system integrates Google Sheets API and email automation to assist recruiters in managing hiring pipelines efficiently.
