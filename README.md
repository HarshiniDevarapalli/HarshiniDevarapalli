### Next Best Decision Engine

An AI-powered multi-agent decision intelligence platform that recommends the optimal next action by combining enterprise context, Retrieval-Augmented Generation (RAG), and autonomous reasoning agents. The system aggregates information from multiple sources, evaluates risks and opportunities, and generates explainable recommendations to support faster, data-driven business decisions.

**Tech Stack:** Python, LangGraph, LangChain, FastAPI, ChromaDB, OpenAI, Vector Embeddings, RAG

### Aviation Near Miss Intelligence Platform

An AI-powered aviation safety intelligence platform that leverages NLP, vector search, and Retrieval-Augmented Generation (RAG) to analyze aviation incident reports. The platform enables semantic search, trend analysis, and automated insight generation to support proactive aviation risk assessment.

**Tech Stack:** Python, Sentence Transformers, ChromaDB, RAG, Streamlit, Pandas

---

### AI-Based Clinical Trial Matching System

An AI-driven healthcare solution that matches patients to relevant clinical trials by analyzing Electronic Health Records (EHRs) and eligibility criteria. The system utilizes SciSpaCy, BioBERT, and ClinicalBERT to extract medical entities and generate compatibility scores using a hybrid rule-based and machine learning approach.

**Tech Stack:** Python, SciSpaCy, BioBERT, ClinicalBERT, Machine Learning

---

### AI-Powered HR Agent

An intelligent recruitment automation agent that streamlines candidate screening through resume parsing, automated evaluation, and decision-making workflows. The system integrates Google Sheets API and email automation to assist recruiters in managing hiring pipelines efficiently.

**Tech Stack:** Python, n8n, Google Sheets API, Email Automation

### Fake Job Posting Detection System

A machine learning-based fraud detection system that identifies deceptive job postings using Natural Language Processing techniques and domain credibility analysis. By combining TF-IDF features with company and website validation signals, the model achieves approximately **86% classification accuracy**.

**Tech Stack:** Python, Scikit-learn, TF-IDF, NLP

**Tech Stack:** Sentence-BERT, UMAP, K-Means, Streamlit, Python
